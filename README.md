# Claude Code 101

A static, self-contained guide to Claude Code with a styled HTML version and local webfonts.

## Files
- `index.html`: GitHub Pages entry point
- `claude-code-guide.html`: Source HTML
- `start.md`: Source markdown
- `fonts/`: Self-hosted webfonts

## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. Push this repo to GitHub.
2. Enable Pages (Settings → Pages) and set the source to the root of `main`.
3. Visit `https://<github-username>.github.io/Claude-Code-101/`.

The fonts are self-hosted, so no external font CDNs are required.
